先完整读取同目录的 **SKILL.md**，再按任务阅读其中引用的文档。

解压整个文件夹，交给有本机文件读取、终端或浏览器能力的 AI，并发送：

> 请读取这个文件夹中的 SKILL.md，按其中流程处理我指定的智慧树课程。先核对课程和登录状态，遵守我本次给出的操作、提交范围。

- 支持技能发现：把整个文件夹放入对应技能目录。Codex 通常使用 `~/.codex/skills/`，可用 `$zhihuishu-course-assistant` 调用。
- 不支持技能发现：直接读取 `SKILL.md` 和引用文件。`agents/openai.yaml` 仅是可选界面信息。
- 只有文本对话、无法访问本机文件或浏览器的 AI：能理解流程，但不能直接操作电脑，需要用户或本地执行器运行脚本。

实际课程操作脚本依赖 PowerShell 和 .NET WebSocket，无需 Node、Playwright 或第三方包。可选离线测试另外需要 Node.js 和 `pwsh`。跨系统执行和其他 AI 产品权限配置未全面实测；“可读取 Markdown”不代表“所有 AI 都能自动执行”。

本包不包含账户、登录态、真实课程答案、学生资料或历史答卷。换电脑后由用户重新建立浏览器连接并登录。

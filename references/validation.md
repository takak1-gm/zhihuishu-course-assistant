# 验证范围

创建日期：2026-11-01。流程来自真实操作；打包验证不重新提交真实作业。

- 历史操作：Edge 本机 CDP 连接、翻转课资源读取、按目录视频连播、单选/多选填写及提交，通过刷新清单核实提交。
- 当前包：`scripts/validate.ps1` 检查 Markdown 引用、PowerShell 语法、本机用户路径和提交授权开关；`scripts/offline-test.cjs` 用本机模拟服务验证重复标签页拒绝、精确标签页路由、跨消息分片的长中文传输，以及首次播放、页面内视频切换、手动暂停、自然结束切换、最后一个视频、视频报错和课程不符。
- 未全面验证：其他 AI 的自动发现、非 Windows 原样执行、未来智慧树 DOM、其他账号访问权限。不能保证平台分数。

移植选择器后先做只读检查，再在授权范围做最小操作并验证。离线测试通过不等于当前真实课程已完成。

在包根目录运行 `node scripts/offline-test.cjs` 可重复离线测试；只监听临时回环端口，不连接真实课程或提交作业。客观题点击及真实平台提交未在打包阶段重新实测。
